# MyAIAgent

MyAIAgent is a lightweight AI-powered agent built in C# (.NET) designed for chat, automation tasks, and integration with external APIs.  
The project follows a clean architecture with Models, Services, and a simple Program entry point.

---

## 🚀 Features

- Chat request/response model  
- AI service for handling prompts  
- Clean and extendable architecture  
- Ready for API integration  
- Easy to deploy and scale
